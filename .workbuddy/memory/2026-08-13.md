## 修复：页面功能全挂（时间不显示、按钮点不动）——CDN 失效

- **根因**：jQuery 与 iziToast 引用的字节跳动 CDN（`lf26/lf3-cdn-tos.bytecdntp.com`）链接已失效（jQuery 返回 404、iziToast 超时），页面所有交互依赖 jQuery → 整个页面 JS 瘫痪
- **修复**：将 jQuery 3.6.0、iziToast 1.4.0（js+css）下载到本地 `js/lib/` 目录，`index.html` 改为引用本地文件，彻底摆脱对失效 CDN 的依赖

- 下载源：jquery 3.6.0 89KB、iziToast.min.js 18KB、iziToast.min.css 41KB（CSS 内图片均为 base64 内联，无外部依赖）

## 修复：快捷方式遮挡搜索框 + 收起无效 → 重构为文档流布局

- **根因**：① `.mark` 原为 `position:absolute; margin-top:200px; z-index:2000` 悬浮面板，直接叠在搜索框上；② 时间上移 `translateY(-160%)` 后被书签面板盖住点不到；③ 时间点击的收起逻辑里 `closeBox()` 后又调用 `closeSet()`（上次改的 openBox 恢复书签），互相冲突导致收起无效

- **验证**：jsdom 模拟完整交互（加载→收起→展开→设置开/关→点空白），14 项断言全部 PASS
