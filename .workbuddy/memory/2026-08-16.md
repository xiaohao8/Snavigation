## 移动端适配 + 修复设置面板开合卡顿

用户反馈「手机端打开/关闭设置面板卡卡 + 检查所有页面移动端适配」。
- **卡顿根因（三个）**：
  1. `js/dock.js` 的 `tick()` 用 `requestAnimationFrame` **永久循环**，每帧对 dock 每项 `getBoundingClientRect()` 强制同步重排 → 全页持续重排，开合面板时掉帧。改为弹簧静止(idle)即 `cancelAnimationFrame` 停循环，`running` 标志防重复启动，鼠标移入/移出再 `start()` 重启（桌面磁性放大行为不变）。
  2. `backdrop-filter: blur()` 在移动端 GPU 开销极大（搜索框/面板/玻璃主题），是开合重绘卡顿主因。
  3. 全局 `*, a, p { transition: 0.3s }`（动画所有属性）在移动端无 hover 时纯属浪费，重渲染时引发过渡抖动。
- **css/mobile.css 新增 `@media (max-width:768px)` 性能块**：关闭所有面板/搜索框 `backdrop-filter`（含 `-webkit-`）、玻璃主题半透明面板改纯色 `#120F17` 兜底、移动端 `transition: none`、面板 `fade` 动画缩到 0.4s 并简化阴影；`@media (max-width:640px)` 给 `.set/.mark` 加惯性滚动 `overscroll-behavior: contain`；`@media (max-width:360px)` 时间字号/搜索框留白/快捷方式改 2 列兜底。
- **审计结论**：首页(时间/天气/搜索/dock)、快捷方式(.mark)、设置(.set)、书签面板(#bookmark-panel 内 .scroll-list 已 46vh 滚动)、图标库、Cookie 提示在 ≤640px 均有适配；书签面板内列表已封顶不溢出，无需改。
- **验证**：`node --check js/dock.js` 通过；静态服务器三资源均 200。桌面端因媒体查询阈值(≤768)未受影响；玻璃主题在移动端为性能牺牲毛玻璃（纯色兜底）。
- **权衡**：移动端玻璃主题不再透出毛玻璃（性能取舍），如有需要可后续仅对高端机恢复。

## 移动端「还是异常」二次修复（用户复测：布局错乱 + 卡顿 + 面板打不开/关不上）

用户反馈移动端仍异常（布局错乱 + 还是卡顿掉帧 + 设置/面板打不开或关不上）。本沙箱无法起浏览器渲染（无 Chromium、拦截子进程、无全局包），先 AskUser 确认三类现象再逐一修。
- **根因①（dock 触屏膨胀）**：dock 磁性放大基于鼠标 `mousemove/mouseleave`。触屏 tap 会触发合成 `mousemove`→`panelHovered=1` 但**没有** `mouseleave`，dock-outer 从 68px 膨胀到 256px 且不收起 → 布局错乱 + 持续重排卡顿 + 点击目标漂移（打不开/关不上）。
- **修复①（js/dock.js）**：新增 `hoverCapable = matchMedia('(hover: hover) and (pointer: fine)')`（try/catch 兜底 false）。仅桌面鼠标才绑定 `mousemove/mouseleave` 并 `start()` 弹簧循环；移动端不启动任何 rAF、dock 用纯 CSS 静态尺寸（≤640px 44px），点击导航照常（click 处理器不 gate）。
- **根因②（设置面板内部固定高度）**：`.set_blocks_content` 430px、`.set_blocks` 340px、`.add_content` 320px 固定高度，在 68vh 窄屏面板里挤压错乱。
- **修复②（css/mobile.css ≤640px）**：这三处改 `height:auto; min-height:0`，`.set_blocks_content` margin 12px，`.add_content` `overflow-y:visible`（统一交给 `.set` 滚动），设置/书签 tab 字号 0.8rem 防裁切。
- **验证（jsdom，5/5 PASS）**：touch 端 load 无 JS 错误、rAF 未启动（无重排环）、点设置 dock 项触发 openSet；desktop 端 load 无错误、rAF 正常启动（弹簧动画保留）。脚本在 `%TEMP%/dock-mobile-test.js`（jsdom 在 node workspace）。
- **遗留**：沙箱无法真机渲染，最终视觉需用户在手机/窄屏硬刷新（Ctrl+Shift+R）确认；若仍有局部错位需截图再定。
