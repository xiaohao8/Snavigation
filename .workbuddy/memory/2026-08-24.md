# 2026-08-24

## 新增：PWA（可安装到桌面 / 离线访问）

让 Snavigation 变成可安装的 Web App：用户可"添加到桌面"，像 App 一样启动，并支持离线访问。

### 新增/修改文件

- **新增** `manifest.webmanifest`（根目录）：name/short_name/start_url=`./?source=pwa`/display=standalone/theme&background=#404040/icons(192/512 any+maskable, 144 any)/shortcuts(快捷方式、设置)。
- **新增** `sw.js`（根目录）：service worker，预缓存 app shell(index.html + manifest + 5 个 PWA 图标 + favicon)，导航 network-first 回落 shell，同源静态 cache-first + 运行期缓存，跨域直通；版本化缓存名 `snavigation-v1`。
- **新增** `js/pwa.js`：注册 sw.js；捕获 `beforeinstallprompt` 暴露给自定义 UI；监听 `appinstalled` 持久化 `snavigation_pwa_installed`；iOS Safari 检测（无 beforeinstallprompt 时显示分享面板指南）；独立窗口检测(`(display-mode:standalone)` + `navigator.standalone`)；在线/离线状态同步；PWA 快捷方式深链 `?source=pwa&goto=shortcuts|settings`。
- **新增** 5 个图标（`img/icon/`）：`pwa-192.png` / `pwa-512.png`（any，透明背景）/ `pwa-maskable-192.png` / `pwa-maskable-512.png`（#404040 满铺，适配 OS adaptive icon 圆形遮罩）/ `apple-touch-icon.png`（180px）。
- **修改** `index.html`：head 增 `link rel=manifest`、`meta theme-color`、`apple-touch-icon`、`apple-mobile-web-app-*`；设置左菜单新增 "App" tab(id=`set-app-menu`)及对应 `.mainConts`（安装按钮 + iOS 指南 + 连接状态/应用名称/启动方式/版本信息卡）；body 增浮动安装按钮(id=`pwa-fab`+关闭); 增 `pwa.js` 脚本(defer, 末尾加载)。
- **修改** `css/style.css`（末尾新增 PWA 区块）：`.pwa-card / .pwa-card--ios / .pwa-card--info / .pwa-btn / .pwa-ios-steps / .pwa-info-row / .pwa-dot / .pwa-fab`。**全程使用现有主题变量** (`--main-background-color` / `--main-text-color` / `--main-button-color` / `--main-search-shadow`)，dark/glass 双主题自动适配。移动端隐藏 FAB 文字仅留图标。

### 关键设计

- **图标生成**：用 PIL 从 `favicon_144.png` 升采样（LANCZOS）；标准图标透明背景，maskable 用 #404040 满铺 + 居中缩放至 70%（落在 80% 安全区内），apple-touch 同样 #404040 满铺 78% 居中。
- **触发逻辑**：浏览器在 PWA 满足可安装条件时自动 fire `beforeinstallprompt` → pwa.js 缓存该事件 → 显示自定义 UI；安装完成 fire `appinstalled` → 持久化标记 + 隐藏 UI + 禁用按钮；iOS 无此事件，直接展开操作指南；关闭 FAB 写 `snavigation_pwa_dismissed` localStorage。
- **离线策略**：预缓存保证 UI shell 离线可用；cache-first + 运行期缓存保证任意新文件首次访问后即可离线。

### 部署注意

- Vercel 部署无需额外配置（`vercel.json` 已存在）。manifest 与 sw.js 在根路径，scope 自动为 `/`。
- 用户首次访问需满足：HTTPS（或 localhost）+ manifest 合规 + sw.js 有 fetch handler + 用户与页面有交互（Chrome 72+ 自动检测；Edge/Firefox/Safari 行为略不同）。
- 调试：Chrome DevTools → Application → Manifest / Service Workers 可查看注册状态。
