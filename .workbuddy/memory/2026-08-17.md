## 修复 51.la 统计"无数据"

用户反馈 51.la 后台无数据。根因：index.html 第 3-4 行原写法 `async` SDK + 紧跟的内联 `LA.init` —— `async` 脚本异步加载，内联脚本执行时 `LA` 通常仍是 undefined，`try/catch` 吞掉 ReferenceError → init 从未执行 → 无数据。
**修复**：合并为单行，`LA.init` 挂到 SDK 的 `onload`（`onload="try{LA.init({id:'K5VNb8is7homMNlQ',ck:'K5VNb8is7homMNlQ',autoTrack:true})}catch(e){}"`），既保证 SDK 加载完才初始化，又保留 `async` 不阻塞秒开。已 grep 验证。
**注意**：51.la 是用户在部署后的线上域名访问才统计；本地 127.0.0.1/file:// 通常不计或不准；且线上 Vercel 需重新部署（当前改动未 push）后硬刷新才能生效。
