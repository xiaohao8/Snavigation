# 2026-08-22

## 优化「设置页 ↔ 快捷方式页」选项同步

- 问题：`.mark`（Dock 打开的快捷方式页）原本是 **硬编码静态 HTML**（8 分类 tab），与设置页「快捷方式」tab 管理的 `quick_list` cookie 完全脱节，无法同步/管理。
- 方案：让 `.mark` 改为由 `quick_list` 动态渲染，与首页 `.quick-all`、设置页「快捷方式」tab 共用 **同一数据源**，实现统一管理与状态同步。
- 关键改动（js/set.js）：
  - 新增 `QUICK_CATS = ['常用','AI','工具','办公','开发','娱乐','学习','设计']` 与 `renderMarkShortcuts()`：读取 `getQuickList()`，按 `cat` 归集到各分类 `.mainCont` 的 `.quick-alls`（只替换内部 HTML，保留 `.mark` 容器与 tab 切换）。
  - `openBox()`、文档 ready、以及快捷方式 新增/覆盖/编辑/删除/重置 各分支均调用 `renderMarkShortcuts()`。
  - `quick_list_preinstall` 33 条默认项增加 `cat` 字段（按 8 分类分布；AI/设计 默认空，显示 `.mark-empty` 提示）。
  - 设置表单 `quick_add_content` 增加「分类」下拉框；`quick_add_save` 读写 `cat`，`edit_quick` 回填；`[data-mark-add]` 从对应分类「添加」入口进入设置时预选该分类。
  - 书签增改删后调用 `BookmarkPanel.refresh()`。
- CSS：新增 `.add_content select`（对齐输入框）与 `.mark-empty` 样式。
- 验证：用最小 DOM 桩在 node 沙箱中真实执行 `renderMarkShortcuts`，确认 33 条按分类正确归集、空分类显示提示、无异常（PASS）。
- 注意：`.mark` tab 顺序与 `QUICK_CATS` 必须一致，否则分类错位。
